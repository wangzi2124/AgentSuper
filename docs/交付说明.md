## 三、数据流

```
tool_execute(mvn -v)
  → _validate_shell_command(ask=True)
    → _check_single_allowed("mvn", ask=True)
      → check_command("mvn") → 未命中 → external_default="ask"
      → NeedsPermission("mvn", "command", "tool_execute", {"command": "mvn -v"})
  → graph.py except NeedsPermission
    → create_request → 前端弹窗（执行命令 / mvn -v）
    → 用户点"允许并记住"
      → respond(remember=True) → _command_whitelist.add("mvn") → command_permissions.json
    → add_temp_command_approval("mvn")
    → 重试 _validate_shell_command(ask=True) → check_command 命中 → 放行
```

## 四、安全红线（永不因 ask 放松）

1. 命令黑名单（`_DANGEROUS_PATTERNS`）在 ask 之前执行，命中即拒绝
2. SSRF 校验不放松
3. 反引号 / `$(...)` 内层命令递归校验，ask 参数透传
4. 分段校验不放松（`cat x | evil` 中 evil 段同样弹窗）
5. `external_default=deny` 时行为与改造前完全一致（零回归）
6. 「允许并记住」只记录 base 命令，不记录参数
