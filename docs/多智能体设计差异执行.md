## D3 具体设计

- **helpers.py**：新增 `async _generate_title_llm(messages) -> str`
  - prompt：`用 10 个字以内概括对话主题，只输出标题，不要引号或标点。`（对齐设计 Phase 4）
  - `litellm.acompletion`，`temperature=0.5`，`max_tokens=30`，`cache_prompt=True`
  - 清洗：去空白/引号/句号 + `html.escape`，截断 30 字
  - 失败（无 key / 异常 / 空结果）→ 回退 `_generate_title`（规则截取），标题总可用
- **persist.py** `_persist_multi_agent`：首条消息（`latest_seq == 1`）
  - 先同步落规则标题（保证会话立即有标题）
  - 再 `asyncio.create_task` 后台异步 LLM 生成并 `service.update` 覆盖为 LLM 标题
  - 后台任务整体 try/except，失败仅记日志（保留规则标题）
- 不在请求主路径内等待 LLM：写锁持有期内调用，不阻塞 /stream 收尾

## 验证
