### 计分公式 `calcScore`（第 141-146 行）

```js
export function calcScore(cleared, level, combo) {
  if (!cleared) return 0
  const base = LINE_SCORES[cleared] || 0
  const comboBonus = combo > 0 ? combo * 50 : 0
  return base * level + comboBonus
}
```

即：`得分 = 基础分(1/2/3/4行 → 100/300/500/800) × 等级 + (combo>0 ? combo×50 : 0)`。

### 等级与速度 `levelSpeed`（第 63 行）

```js
export const levelSpeed = (level) => Math.max(80, 800 - (level - 1) * 70)
```

即：`间隔 = max(80, 800 - (level-1)×70)` 毫秒，等级越高越快，下限 80ms。

export function createBag() {
  const bag = [...TYPES]
  for (let i = bag.length - 1; i > 0; i--) {
